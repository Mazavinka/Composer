Composer

Десктопное приложение, которое автоматизирует подготовку изображений-шаблонов для промышленного печатного оборудования (ковровая фабрика)

Экономия времени: До этого операторы вручную вырезали и склеивали изображения, что занимало 30–60 минут на один заказ.
После внедрения программы процесс стал полностью автоматическим — ошибок меньше, скорость выше.

## Стек
Python 3.11 • pandas • openpyxl • Pillow • PyQt5/Tkinter • requests • sqlite3

## Быстрый старт
1) Создать окружение и установить зависимости:
   python -m venv .venv
   .venv\Scripts\activate  # Windows
   pip install -r requirements.txt
2) Запуск:
   Запускать через main.py

Как работает
Программа читает Excel-заявку, в которой указаны палитры, размеры, рисунки и другие параметры.
Затем находит соответствующие файлы изображений, автоматически собирает их в нужную компоновку и подготавливает итоговый шаблон для печати.

## Ограничения
Коротко: требования к формату файлов/окружению.
